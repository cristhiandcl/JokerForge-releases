# JokerForge releases

Public installer downloads and release notes for JokerForge.

## Downloads

Installers will appear on the [Releases page](https://github.com/cristhiandcl/JokerForge-releases/releases) after release validation is complete. No public release is available yet.

The installer targets are macOS Apple silicon and Windows x64/ARM64. Platform requirements and changes will be included with each published release.

## Updates and support

In-app updates and private, optional error reporting are being prepared. Use the installation and update instructions supplied with your release. Keep your existing workspace when replacing the app.

This repository hosts release downloads and notes. It does not collect private diagnostic reports. Do not post credentials, private conversations or diagnostic bundles here.

JokerForge builds on Omnigent and other open-source components. Release packages include applicable notices and corresponding source materials.
